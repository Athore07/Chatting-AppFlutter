# 💬 Flutter Firebase Chat App

> A beautiful real-time chat application built using **Flutter** and **Firebase** 🔥  
> Developed as a collaborative group 13 team project with full GitHub participation tracking.

---

## ✨ Features

✅ User Authentication (Email & Password)  
✅ View Registered Users  
✅ Real-time 1-to-1 Messaging  
✅ Push Notifications (Firebase Cloud Messaging)  
✅ Clean & Modern UI  
✅ GitHub Collaboration with Multiple Contributors
